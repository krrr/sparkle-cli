# Sparkle CLI Companion

The Sparkle CLI Companion extension pairs with
[Sparkle CLI](https://github.com/krrr/sparkle-cli). This extension is compatible
with both VS Code and VS Code forks.

# Features

- Open Editor File Context: Sparkle CLI gains awareness of the files you have
  open in your editor, providing it with a richer understanding of your
  project's structure and content.

- Selection Context: Sparkle CLI can easily access your cursor's position and
  selected text within the editor, giving it valuable context directly from your
  current work.

- Native Diffing: Seamlessly view, modify, and accept code changes suggested by
  Sparkle CLI directly within the editor.

- Launch Sparkle CLI: Quickly start a new Sparkle CLI session from the Command
  Palette (Cmd+Shift+P or Ctrl+Shift+P) by running the "Sparkle CLI: Run"
  command.

# Requirements

To use this extension, you'll need:

- VS Code version 1.99.0 or newer
- Sparkle CLI (installed separately) running within the integrated terminal
